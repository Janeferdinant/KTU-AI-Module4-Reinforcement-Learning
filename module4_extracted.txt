Reinforcement Learning (RL) 
1.1 What is Reinforcement Learning? 
Reinforcement Learning (RL) is a type of machine learning in which an agent learns how to 
make decisions by interacting with an environment and receiving rewards or penalties. 
The goal is to learn a strategy that maximizes the total reward over time. 
Example: A robot learns to navigate a room. It receives a positive reward for reaching its 
destination and a penalty for hitting obstacles. 
 
1.2 Important terms 
• 
Agent: The learner that selects actions. 
• 
Environment: The external world with which the agent interacts. 
• 
State (𝒔): The current situation of the agent. 
• 
Action (𝒂): A choice made by the agent. 
• 
Reward (𝒓): Feedback indicating how good or bad an outcome is. 
• 
Policy (𝝅): A strategy for selecting actions in different states. 
• 
Return: The total accumulated reward. 
• 
Value function: The expected long-term reward from a state or state-action pair.

2. Passive Reinforcement Learning 
2.1 Definition 
In passive reinforcement learning, the agent follows a given, fixed policy and learns the 
utility or value of the states it visits. 
The agent does not decide which policy is best. It evaluates the policy it has been given. 
Example: A delivery robot follows a predetermined route and learns the expected reward 
associated with each location.

3. Active Reinforcement Learning 
3.1 Definition 
In active reinforcement learning, the agent chooses actions, observes their results, and 
learns which actions produce the highest long-term reward. 
Unlike passive RL, the agent must learn both: 
• 
How good the current states and actions are. 
• 
Which actions it should choose to improve its performance. 


=== PAGE 5 ===
Example: A robot explores different routes to discover which route reaches its destination 
safely and quickly. 
3.2 Main concepts 
1. Exploration: Trying actions to gain new information about the environment. 
2. Exploitation: Choosing the action currently believed to be the best. 
A good RL agent must balance exploration and exploitation.

3.4 SARSA (On-Policy Algorithm): 
SARSA stands for State-Action-Reward-State-Action, representing the tuple (s, a, r, s', a'). 
Unlike Q-learning, SARSA is an on-policy method. Its update rule relies on the actual next 
action a' selected by the agent's current behavioural policy: 
Q(s, a) ← Q(s, a) + α [ R(s, a) + γ Q(s', a') - Q(s, a) ] 
SARSA takes exploration risks into account during training, making it safer in environments 
where exploratory actions carry high penalties or costs.

4. Generalization in Reinforcement Learning 
4.1 Definition 
Generalization is the ability of a reinforcement learning agent to apply what it has learned in 
familiar states to new or previously unseen states. 
In large problems, it is usually impossible to store a separate value for every state-action 
pair. Generalization helps the agent learn from limited experience. 
Example: A robot trained to navigate several rooms can use the knowledge it has acquired to 
navigate a new room with a similar layout. 
4.2 Why is generalization needed? 
• 
Real-world environments can have enormous state spaces. 
• 
Many states may never be visited during training. 
• 
Learning a separate value for every state is expensive. 
• 
Similar states may require similar actions.

5. Policy Search 
Policy search is an approach to reinforcement learning that directly searches for a policy that 
maximizes expected cumulative reward. 
Instead of first learning an accurate value function for every state, policy search adjusts the 
policy's parameters to improve performance. 
A policy may be represented as

3. Measure the cumulative reward. 
4. Adjust the parameters to improve expected performance.

6. Apprenticeship Learning and Inverse Reinforcement Learning 
6.1 Apprenticeship learning 
Apprenticeship learning is a method in which an agent learns to perform a task by observing 
demonstrations from an expert. 
Instead of learning entirely through trial and error, the agent uses expert behavior as 
guidance. 
Example: A robot observes a human moving objects and learns to perform a similar task. 
Typical steps: 
1. Collect expert demonstrations. 
2. Identify patterns in the expert's behavior. 
3. Learn a policy or infer the objective behind the behavior. 
4. Evaluate the learned behavior. 
5. Improve it using additional demonstrations or interaction. 
6.2 Inverse Reinforcement Learning (IRL) 
Inverse Reinforcement Learning attempts to infer the reward function that explains an 
expert's behavior. 
In ordinary reinforcement learning, the reward function is given or specified. In IRL, the 
agent observes expert behavior and tries to determine what the expert is trying to achieve. 
For example: 
• 
Expert behavior: A driver slows down near pedestrians. 
• 
Possible inferred reward: Avoid collisions and maintain safety. 
• 
Learned policy: Drive cautiously when pedestrians are nearby. 
The inferred reward is not necessarily unique; several reward functions may explain the 
same behavior.

7. Applications of Reinforcement Learning 
Reinforcement learning is useful when actions influence future outcomes and the agent can 
improve through feedback. 
1. Robotics and automation 
Robots learn movement, object manipulation, path planning, and control strategies. 
Example: A robotic arm learns how to pick and place objects accurately. 
2. Autonomous vehicles 
RL can help optimize simulated driving policies, lane changes, and traffic responses. 
Example: Learning a policy that balances smooth driving and safe following distances. 
3. Games 
Agents learn strategies through rewards, simulations, and repeated play. 
Example: Learning strong strategies in chess or other games. 
4. Power systems and energy management 
RL can optimize energy storage, building energy use, and resource allocation. 
Example: Scheduling battery charging to reduce electricity costs while meeting operational 
constraints. 
 
5. Computer networks 
RL can support routing, congestion management, and allocation of network resources. 
Example: Selecting routing policies that reduce delay and congestion. 
 
6. Healthcare 
RL research explores sequential treatment decisions and resource scheduling. 
Example: Optimizing treatment strategies under carefully validated clinical constraints.
